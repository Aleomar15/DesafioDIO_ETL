
# DesafioDIO_ETL
# Sobre o Projeto
Fluxo ETL (Extração, Transformação e Carregamento), utilizando um arquivo csv contendo os id's' dos usuários, mais uma lista de dicionários complementares que contem as informações do usuário. Para cada usuario usado no processo foi utilizado a API do Gemini na versão 2.0 flex para criar mensagens personalizadas para cada usuario.

  
Como faz para executa-lo?
- Pode ser executado online no [Google Colab](https://colab.research.google.com/#)
